This demo covers linking, *Threads*, structure, and the core workflow tools. Foma has more. A few worth trying, whenever you are ready:

- `/guide` — the full feature reference. Start here.
- `/export` — compile the manuscript into a finished file.
- `/reader` — read your manuscript like a book.
- `/memory` — save a named snapshot of the whole project.
- `/compare` — see what changed between drafts.
- `/git` — the full version-control terminal, for the deeper tools.
- `/comments` (Ctrl+Alt+M) — leave notes on any passage.
- `/search` (Ctrl+F) — find text across the project.
- `/sprint` — timed writing sprints.
- `/phonemode` — Phone Mode.
- `/emoji` — the emoji picker.

Writing Stats lives in the title bar, and `/dim` is available once you are inside Focus Mode.
