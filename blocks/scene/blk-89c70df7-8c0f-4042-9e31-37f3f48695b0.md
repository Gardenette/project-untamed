These features are non-essential, but when considered together, can contribute to a much smoother workflow and writing experience.

## Editor Settings & Features

* **Auto-capitalize 'I'** — from `Settings → Editor`, toggle "Auto-capitalize I" to ensure that, when writing in first person perspective, you never have to hold Shift or Caps Lock for the letter 'i' to correct to 'I' when typed in isolation.

* **Home Row Workflow** — Almost anything you wish to accomplish in Foma can be done with both hands on the keyboard. Foma contains a robust slash command palette that exposes virtually every feature, function, or formatting action by typing `/`.

* **Markdown Syntax Shortcuts** — Foma respects Markdown formatting. For example, while an H1 can be created by typing `/heading1`, it can also be created by beginning a new line and typing `#` + space. Most markdown syntax converts to formatting in the editor.

* **Markdown Copy/Paste** — Markdown syntax that is pasted into Foma automatically converts to formatted text.

* **Auto-indent on Enter** — from `Settings → Editor`, toggle this on to automatically indent each new paragraph by default.

* **Scene-level reading estimation** — The current document is given an estimation on how long the scene is, reflected as either "time to read" or "number of pages". The bottom-right corner of the footer bar displays the estimation. To toggle between views, simply click on the estimation.

* **Actant Link Settings&#x20;**— By default, *Actant* Links are styled as "*Subtle*", meaning that they do not draw any attention to themselves while reading text in the Editor. The only way to know if an *Actant* is linked to a word in the manuscript is to inspect the word with the cursor. However, if you prefer to see all linked *Actants* more prominently at a glance, navigate to `Settings → Editor → Link style` and choose whether you prefer *Subtle*, *Moderate*, or *Prominent&#x20;*&#x73;tyling.

## Import & Export Features

Foma offers flexible, powerful import and export capabilities.

### Import Wizard

Stories that have been outlined in Plottr or written in Scrivener can be imported into Foma using the Import Wizard. When creating a new project, once you've chosen the location where the Foma project will be saved, select Plottr or Scrivener import and use the Wizard to guide you through import options.

The Foma Import Wizard previews the story structure to make it easier to make informed decisions about how your outline or manuscript will convert to Foma conventions.

### Exports

Foma projects can be exported in `.docx`, `.pdf`, or `.epub` formats. Foma also features a dedicated, lean eBook reader in which you can preview your story as an eBook before committing to an `.epub` export.

* Export your project through `Settings → Tools → Export Manuscript` or by typing `/export` in the editor.

* View your project as an eBook through `Settings → Tools → EPUB Reader` or by typing `/read` in the editor.
